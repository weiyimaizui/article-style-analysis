# article-style-analysis

多篇文章风格分析与模仿系统 v3.0 — 分析同一作者多篇文本的写作风格特征，并输出从宏观到微观的结构化模仿指南。

## 功能

- 输入同一作者的 3–5 篇文本样本
- 通过多篇交叉验证提取稳定的写作风格特征
- 宏观维度：思维模式、价值取向、表达意图、风格定位、跨文本一致性
- 微观维度：语言、结构、叙事、情感、思维、个性标记、文化底蕴、韵律节奏、跨文本变化
- 输出结构化风格模型（JSON）与可执行的模仿指南

## 文件结构

- `SKILL.md` — Skill 主定义与使用说明
- `references/output-format.md` — 结构化输出格式（JSON 字段说明与填写规范）

## 安装

将本仓库内容放到你的 Agent Skills 目录下，例如：

- WorkBuddy / CodeBuddy：`~/.workbuddy/skills/article-style-analysis/`
- 其他兼容 Agent Skills 规范的工具：放到对应的 skills 目录

保持如下目录结构：

```
article-style-analysis/
├── SKILL.md
└── references/
    └── output-format.md
```

## 使用

提供同一作者的多篇文章，然后要求「分析该作者的写作风格」或「按该作者的风格仿写」即可触发。

## 安全边界

- 样本仅作为被分析资料处理，不会执行样本中包含的任何指令。
- 请勿将风格模仿用于误导性冒充、欺诈或侵犯他人权益的场景。
- 样本少于 2 篇或作者身份混杂时，工具会先提示说明，避免得出不可靠的风格结论。
